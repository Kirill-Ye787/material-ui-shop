# Forma — E-commerce Product Catalog

Полный учебный проект по заданию **«Використання Material-UI у React»**, для работы в **WebStorm 2026.2.3**. Интерфейс на украинском языке, инструкции на русском.

В проекте 120 товаров, 6 категорий, 20 брендов. Каталог поддерживает поиск, совместные фильтры, пять способов сортировки, сетку/список и пагинацию по 12 товаров. Есть страница товара с галереей, вариантами и вкладками, корзина, избранное, сравнение до 4 товаров, быстрый просмотр и тёмная тема.

## Запуск

Нужен Node.js 22.12 или новее. Можно использовать установленный у вас Node.js 24. Откройте в WebStorm папку, в которой находится `package.json`. В терминале **Alt + F12** выполните:

```powershell
npm install
npm run dev
```

Откройте адрес из терминала, обычно **http://localhost:5173/**. Каталог: **http://localhost:5173/catalog**.

Пошаговая инструкция по созданию проекта вручную, работе в WebStorm и загрузке через сайт GitHub находится в [WEBSTORM_GUIDE.md](WEBSTORM_GUIDE.md).

## Подходы к стилям

| Часть проекта | Стилизация | Основные файлы |
| --- | --- | --- |
| Header и навигация | CSS Modules + SCSS | `src/components/Header/` |
| Фильтры | Material UI | `src/components/Sidebar/FilterSidebar.jsx` |
| Каталог, карточки и сетка | Только Tailwind utility-классы | `src/pages/Catalog/`, `src/components/ProductCard/`, `src/components/ProductGrid/` |
| Галерея и верх страницы товара | CSS Modules | `src/components/ImageGallery/`, `src/pages/ProductDetail/ProductDetail.module.scss` |
| Вкладки, характеристики, выбор опций, действия | Material UI | `src/pages/ProductDetail/ProductDetail.jsx` |
| Рекомендации на странице товара | Tailwind | `src/pages/ProductDetail/ProductDetail.jsx` |
| Список корзины | Material UI List, IconButton, Collapse | `src/components/Cart/CartItem.jsx` |
| Итоги корзины | CSS Modules; MUI-поля и кнопки | `src/components/Cart/CartSummary.jsx`, `src/pages/Cart/Cart.module.scss` |
| Избранное | Обычный SCSS | `src/pages/Wishlist/Wishlist.scss` |
| Footer | Обычный CSS | `src/components/Footer/Footer.css` |
| Сравнение | CSS Grid + CSS Modules | `src/pages/Comparison/` |

Применён **Tailwind CSS 3.4.18**, поскольку задание использует `tailwind.config.js`, PostCSS и директивы `@tailwind`. MUI и Emotion подключены через `ThemeProvider` и `StyledEngineProvider injectFirst`. Tailwind Preflight выключен: базовый сброс выполняет MUI `CssBaseline`. В карточках и каталоге нет собственных CSS-классов или inline-стилей.

В `Wishlist.scss` специально сохранены запрошенные `@import`, `lighten`, `darken`, переменные, nesting, mixins и функция `calculate-columns`. Для остального SCSS используется `@use`. Предупреждения о запрошенных устаревающих SCSS-конструкциях отключены адресно в конфигурации Vite.

## Что проверить в интерфейсе

1. Откройте каталог. Выберите несколько категорий, бренд, цену, рейтинг и доступность. Изменения отражаются в URL. Кнопка сброса очищает фильтры и поиск.
2. Измените сортировку, переключите вид, откройте вторую страницу. На странице показывается не более 12 товаров.
3. Нажмите сердечко, иконку быстрого просмотра или сравнения. Счётчики в шапке обновятся.
4. Откройте товар. Переключите 4 изображения, откройте lightbox, выберите цвет и размер. У смартфонов/планшетов можно выбрать память с изменением цены.
5. Добавьте товар в корзину. Разные варианты сохраняются отдельно; одинаковые объединяются. Остаток ограничивает суммарное количество товара по всем вариантам.
6. В корзине измените количество, удалите позицию, нажмите **«Відмінити»** в уведомлении. Примените промокод **FORMA10**.
7. Перезагрузите страницу: корзина, избранное, сравнение и тема сохраняются.
8. В избранном добавьте все товары в корзину или скопируйте ссылку. Ссылка содержит идентификаторы товаров; открывший её пользователь видит этот список и может сохранить себе.
9. На узком экране откройте бургер-меню и отдельную панель фильтров.

## Расчёт стоимости

- Стоимость позиции: цена товара плюс надбавка за выбранную память, умноженная на количество.
- Промокод **FORMA10** даёт скидку 10% на сумму товаров с округлением до целой гривны.
- Доставка: **99 ₴**, бесплатно при сумме товаров до промокода **от 3 000 ₴**.
- Скидка распродажи уже включена в цену товара; повторно она не вычитается.

## Команды

```powershell
npm run dev
npm test
npm run build
npm run preview
```

`npm test` запускает проверки данных, сочетания фильтров, сортировки, вариантов корзины, остатков, восстановления данных, надбавки за память, промокода и доставки. Для проверки интерфейса следуйте сценарию выше.

После `npm run build` появляется папка `dist`. Она не нужна для сдачи исходного кода. Для повторяемой установки зависимостей с включённым `package-lock.json` можно использовать `npm ci`.

## Данные и ограничения учебного проекта

Это frontend без сервера, реальной авторизации и платёжной системы. Данные товаров, брендов, характеристик, остатков, отзывов и контактов демонстрационные. Оформление показывает локальное подтверждение и очищает корзину без отправки личных данных. Профиль сохраняет только имя на этом устройстве. Контактная форма проверяет ввод локально.

52 SVG-иллюстрации включены в `public/images`; внешние сервисы изображений не нужны. Товары генерируются детерминированно в `mockProducts.js`, поэтому IDs и ссылки стабильны. При отсутствии истории просмотра блок рекомендаций использует товары из демо-каталога. Копирование ссылки на избранное требует доступного Clipboard API; предусмотрено ручное копирование. Ссылка на localhost работает на том же компьютере; для обмена между устройствами потребуется опубликовать проект с доступным адресом.
