# Работа в WebStorm 2026.2.3 и сдача через GitHub

## Если создаёте проект самостоятельно

1. Откройте WebStorm и выберите **File → New → Project**.
2. Выберите пустой проект **Empty Project** и укажите папку, например `D:\ReactProjects\material-ui-shop`.
3. Создайте в корне файлы `package.json`, `index.html`, `vite.config.js`, `tailwind.config.js`, `postcss.config.js` и `.gitignore`.
4. Создайте папки `src`, `public` и `tests`. Внутри создавайте подпапки и файлы, сохраняя пути из готового проекта. **New → Directory** создаёт папку, **New → File** создаёт файл.
5. Перенесите код в соответствующие файлы. Всё содержимое `public/images` тоже нужно перенести. Можно скопировать папки целиком из распакованного архива в созданную папку проекта.
6. Если перенесли `package-lock.json`, сохраните его в корне рядом с `package.json`.
7. Откройте терминал **Alt + F12**. Убедитесь, что он открыт в корне проекта, а не в `src`.
8. Выполните `npm install`, затем `npm run dev`.

Генератор Create React App не нужен: этот проект настроен на Vite. Команда `npm install` сама создаёт папку `node_modules`; создавать её вручную не нужно.

## Если запускаете готовый архив

1. Распакуйте ZIP.
2. Выберите **File → Open** и откройте папку `material-ui-shop`, где виден `package.json`.
3. Если WebStorm спрашивает, доверяете ли вы этому проекту, подтвердите доверие к проверенным вами файлам.
4. Откройте терминал **Alt + F12** и выполните:

```powershell
npm install
npm run dev
```

5. Откройте адрес из терминала, обычно **http://localhost:5173/**. Для каталога добавьте `/catalog`.
6. Чтобы остановить сервер, нажмите **Ctrl + C** в терминале.

Если PowerShell сообщает, что `npm.ps1` не может быть запущен, используйте команды без изменения настроек Windows:

```powershell
npm.cmd install
npm.cmd run dev
```

Проверить Node.js:

```powershell
node -v
npm -v
```

Для этого проекта используйте Node.js 22.12 или новее; Node.js 24 подходит.

## Как ориентироваться в файлах

| Где находится файл | Что он делает |
| --- | --- |
| `package.json` | Зависимости и команды запуска |
| `index.html` | Стартовая HTML-страница |
| `src/main.jsx` | Подключает React, Router, провайдеры и стили |
| `src/App.jsx` | Маршруты и общий layout |
| `src/pages/` | Страницы магазина |
| `src/components/` | Повторно используемые элементы интерфейса |
| `src/context/` | Общие корзина/избранное/сравнение и тема |
| `src/hooks/` | Custom hooks корзины, избранного, фильтров и хранения |
| `src/data/` | Товары, категории и бренды |
| `src/styles/` | Общие CSS/SCSS и Tailwind directives |
| `src/utils/` | Фильтры, цены, корзина, localStorage |
| `public/images/` | Локальные изображения |
| `tests/` | Проверки логики |

## Какие файлы загрузить на GitHub

В корень репозитория загрузите:

- `src/` целиком;
- `public/` целиком;
- `tests/`;
- `package.json` и `package-lock.json`;
- `index.html`;
- `vite.config.js`, `tailwind.config.js`, `postcss.config.js`;
- `.gitignore`;
- `README.md`, `WEBSTORM_GUIDE.md`, `TASK_COVERAGE.md`.

**Не загружайте** `node_modules`, `dist`, `.idea`, `.vscode`, логи и ZIP-архив как замену исходным файлам. `.gitignore` содержит исключения, но при ручной загрузке через сайт GitHub выбирать ненужные папки всё равно не следует.

## Загрузка через сайт GitHub

1. Создайте новый репозиторий, например `material-ui-shop`.
2. Откройте страницу загрузки: **Add file → Upload files**; у пустого репозитория также есть ссылка **uploading an existing file**.
3. Откройте папку проекта в Проводнике Windows. Перетащите **сами папки `src`, `public`, `tests` и нужные файлы из корня** на область загрузки GitHub.
4. Обычная кнопка выбора файлов может не выбирать папки. Для папок используйте перетаскивание из Проводника, чтобы сохранились вложенные пути.
5. В этом проекте больше 100 файлов с учётом изображений. Если форма ограничивает количество файлов, загрузите сначала корневые файлы и `src`, затем отдельным коммитом `public`, затем `tests`. Сохраняйте пути папок.
6. Введите сообщение коммита, например `Add React product catalog with Material UI`, и нажмите **Commit changes**.
7. На главной странице репозитория должны находиться `package.json`, `src` и `public`. Если всё находится внутри лишней папки `material-ui-shop`, перенесите файлы в корень репозитория.
8. Скопируйте ссылку на репозиторий и отправьте преподавателю.

После загрузки убедитесь, что на GitHub появился `README.md` и виден полный исходный код. Сам сайт автоматически не запускается от загрузки исходников в репозиторий.

## Проверка перед сдачей

```powershell
npm test
npm run build
```

Затем запустите `npm run dev` и проверьте каталог, фильтры, корзину, избранное, страницу товара и мобильное меню. Промокод для демонстрации — **FORMA10**.
